Given one hot spot (with severity, engineer_ids, days_hot, sprint_critical,
evidence) and the TL escalation rules (provided inline), pick exactly one
response mode and rationale.

## Modes

- `NOTE` — keep on TL's private flag list; watch tomorrow.
- `STANDUP` — raise as a question in tomorrow's standup (team-visible).
- `DM` — draft a direct message to one engineer.
- `ESCALATE` — draft a note for the manager / PM.

## Default heuristics (overridable by the escalation rules)

- days_hot < 2 → NOTE
- days_hot 2-4, individual issue → DM
- days_hot 2-4, team-wide pattern → STANDUP
- days_hot >= 5 OR sprint_critical → ESCALATE
- off-sprint work without obvious justification → DM

Apply the per-engineer and per-module overrides FIRST. Set `target` per mode:
DM → engineer_id; STANDUP → null; ESCALATE → manager_id from rules; NOTE → null.

Output a single `ResponseDraft` (mode + target + body + rationale).
For `body`, write a concise one-sentence placeholder summarising the action
(e.g. "Check in with Matt on ENG-9 migration blockers"). Phase 7 will expand
it into the final message.
