Compose the actual artifact for one approved `ResponseDraft`. The TL's
voice/tone preferences are provided inline below — follow them verbatim.

Inputs:
- The hot spot (with evidence + engineer_ids + ticket_ids)
- The chosen mode (NOTE / STANDUP / DM / ESCALATE)
- The TL's tone preferences (from `config/tl_preferences.md`)
- The Phase 5 deep-dive answer (if any)

Output the `body` text. Format per mode:

- **NOTE**: 1-2 sentence private note. Just the observation.
- **STANDUP**: a single question that names the topic but not the person.
- **DM**: a direct message to the engineer. Lead with the observation,
  one question, leave room for "I'm actually fine".
- **ESCALATE**: 3 bullets — what's happening / what I've tried / what
  I'd like. ≤ 8 lines total.

Hard rules:
- Cite evidence (ticket key, commit SHA).
- Use first name, never the chat handle.
- Don't mention "the agent" — the TL is speaking.
- No emojis.
